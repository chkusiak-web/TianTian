Desktop only

  • No rebuild needed. The trial is already a web page, so this just means removing the touch buttons.
  • It plays in a 16:9 window that scales up evenly, with sharp pixels at 1280×720 and above.
  • Use the keyboard to move and talk. Use the mouse to hover for pinyin and click for English.
